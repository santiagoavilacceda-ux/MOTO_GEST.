# MotoGest - Proyecto Web en HTML, CSS y JavaScript (.js)

Versión pura en **JavaScript Vanilla (.js)** sin necesidad de compilación ni dependencias externas.

## Archivos incluidos
- `index.html` -> Estructura principal de la aplicación MotoGest
- `css/styles.css` -> Guía de estilo oficial (Azul Cobalto #2563EB, Slate #0F172A, Gris Hielo #F8FAFC, Semáforo Verde/Rojo)
- `js/data.js` -> Datos iniciales de clientes, motocicletas, mecánicos, órdenes y garantías
- `js/checkin.js` -> Lógica de la Pantalla A (Entrada / Check-in, síntomas, galería de fotos y creación de orden)
- `js/garantias.js` -> Lógica de la Pantalla B (Buscador, Semáforo automático y radicación RF03)
- `js/kanban.js` -> Tablero de órdenes por estado y carga de mecánicos
- `js/app.js` -> Navegación entre pantallas, persistencia en localStorage e inicialización

## Cómo usarlo
1. Descomprime este archivo ZIP en una carpeta.
2. Haz doble clic en `index.html` para abrirlo en tu navegador, o ábrelo con **Live Server** en VS Code.
